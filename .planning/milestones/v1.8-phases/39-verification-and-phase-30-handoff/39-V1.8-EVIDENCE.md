# v1.8 Implementation Evidence Matrix

This artifact consolidates implementation evidence for the v1.8 Cloud Server Creation Experience milestone. It separates
automated/component/API/repository/source-boundary/build evidence from live Hetzner, Steam, Arma, authenticated browser,
provider mutation, and final provider cleanup evidence.

## Classification

| Label | Meaning |
|-------|---------|
| automated | Local xUnit or build verification that can run without live credentials. |
| component | Service/controller/unit-level behavior proof. |
| API | ASP.NET controller or service contract proof. |
| repository | WebApp repository facade and generated-client boundary proof. |
| source-boundary | Static source test for UI/copy/redaction/route-boundary constraints. |
| build | Solution compile proof. |
| deferred-live | Requires explicit operator approval, credentials, budget, and cleanup window. |
| operator-required | Requires human action or external provider/runtime state. |
