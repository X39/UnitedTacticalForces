| WebApp to API DTO contract | Browser-provided owner, server, provider-option, port, CIDR, modpack, and runtime fields cross into server-side validation. |
| API DTO to generated client | Public OpenAPI surface becomes browser-visible generated models. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-33-02 | Tampering | `GuidedCloudEntryReadinessPayload` | mitigate | Payload is only a transport shape in this plan; Plan 02 must validate all IDs and user-editable values server-side before readiness can be true. |
| T-33-SC | Tampering | Package supply chain | accept | No npm, pip, cargo, NuGet, or tool package installation is planned; verify project files and package manifests are unchanged. |
</threat_model>
