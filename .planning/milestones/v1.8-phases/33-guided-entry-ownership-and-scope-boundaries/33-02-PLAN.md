## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to `GameServersController` | Untrusted ids, titles, provider option names, ports, CIDR, modpack ids, and runtime text enter API validation. |
| Actor to billing owner scope | User-supplied billing account id can attempt account enumeration or assignment escalation. |
| Planning-server create to persisted auth state | New server and creator resource claim are persisted for owner/operator reachability. |

| T-33-04 | Information Disclosure | Billing owner options | mitigate | Non-admins receive only active user-owned billing accounts matching their user id; admins/server admins receive active accounts only. |
| T-33-05 | Tampering | `CreateArma3GuidedCloudEntryServerAsync` | mitigate | Restrict to `Claims.Creation.Server`, normalize title, validate account usability, assign owner through `IBillingOwnershipService`, and grant only the created server's resource claim to the actor. |
