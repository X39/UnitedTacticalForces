<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebApp/API input -> API planner | User-controlled dry-run inputs are normalized and persisted as fingerprint/safe summary state. |
| API persistence -> later review/provisioning checks | Durable state controls whether a reviewed plan is current or superseded. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-01 | Tampering | `Arma3CloudDryRunPlannerService` | mitigate | Compute deterministic fingerprints server-side from normalized fields and persist supersession before returning the new plan. |
| T-35-02 | Information Disclosure | `InputSummaryJson` | mitigate | Store only non-secret labels and ids; tests scan for tokens, credentials, authorization headers, raw payload names, and secret-bearing markers. |
| T-35-03 | Repudiation | Superseded dry-run plans | mitigate | Persist `SupersededByPlanFk` and `TimeStampSuperseded` so later review can explain why a plan is unusable. |
| T-35-SC | Tampering | package installs | accept | No package-manager installs are planned or allowed. |
</threat_model>
