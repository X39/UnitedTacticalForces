## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/repository -> runtime action endpoint | User-triggered runtime actions cross from UI into server authorization and queueing. |
| API -> lifecycle job queue | Runtime actions become persisted jobs consumed asynchronously by cloud workers. |
| Cloud worker -> job claim/progress/failure | Worker reports progress and failure over authenticated worker APIs. |
| Runtime failure -> status projection | Worker/provider/Steam details become sanitized user-visible status. |

</threat_model>
