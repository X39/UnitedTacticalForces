| Audit DTO to UI result | Audit records can contain raw details; cloud workflow summaries must not expose them. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-34-05 | Tampering | lifecycle route calls | mitigate | Use generated request builders instead of raw URL strings where builders exist. |
| T-34-06 | Repudiation | lifecycle action result | mitigate | Preserve lifecycle job id, requested-by id, billing account id, billing assignment id, and timestamps in repository results. |
| T-34-SC | Tampering | package supply chain | accept | No package-manager install is planned. |
</threat_model>
