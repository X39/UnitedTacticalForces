<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> API policy review | Untrusted caller requests policy state for a selected dry-run plan. |
| Client -> API approval commands | Untrusted caller submits approve/deny commands and reasons. |
| API -> provider/lifecycle services | Billable mutation must not happen from policy review or blocked gate results. |
| API -> database | Durable decisions and approvals persist audit context and continuation identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-05 | Elevation of Privilege | `CloudPlanningController.ReviewArma3DryRunPolicyAsync` | mitigate | Require authenticated database user and `Claims.ResourceBased.Server.Configuration`; server validates route `gameServerId`, payload scope, and dry-run existence before evaluating. |
| T-36-06 | Tampering | `ICloudSpendingPolicyGateService.EvaluateProvisioningAsync` | mitigate | Use server-side `acknowledgedDecisionId` and `approvalRequestId` validation; reject stale, expired, denied, mismatched, or missing approvals. |
| T-36-07 | Tampering | Provider mutation boundary | mitigate | Policy-review endpoint returns `CloudSpendingPolicyGateResultDto` and never calls provider provisioning, provider teardown, lifecycle enqueue, Steam, or Arma runtime services. |
| T-36-08 | Elevation of Privilege | `CloudSpendingPoliciesController.ApproveApprovalRequestAsync` / `DenyApprovalRequestAsync` | mitigate | Keep `[Authorize(Claims.Administrative.Server)]`; tests verify non-admin requests cannot resolve approvals. |
| T-36-09 | Repudiation | `CloudSpendingPolicyApprovalService` | mitigate | Persist resolver id, timestamps, sanitized reason, expiration, and audit details for approved and denied requests. |
| T-36-SC | Tampering | npm/pip/cargo/NuGet installs | accept | No package installs are planned; stop if execution proposes a package-manager install because the package audit says no external package is needed. |
</threat_model>
