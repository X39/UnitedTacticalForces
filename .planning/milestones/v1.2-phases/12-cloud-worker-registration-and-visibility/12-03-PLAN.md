<objective>
Expose safe cloud worker/bootstrap/session status to admins and server owners, with state-driven controls and no secret leakage.
</objective>

- sources/Api/DTO/LifecycleWorkerDto.cs
</read_first>
<action>
Add safe cloud session status projections that combine cloud session, resource inventory, bootstrap credential status, and linked lifecycle worker status. Admin endpoints may expose all sessions. Server-owner endpoints under `game-servers/{gameServerId}` should expose only sessions/resources for that game server using existing resource-scoped authorization.
</action>
<acceptance_criteria>
- Admin can inspect provisioning, bootstrap, worker heartbeat, cleanup-needed, orphan-candidate, teardown, and deleted states.
- Server owners can inspect cloud provisioning/bootstrap status for only their accessible server.
- DTOs include safe flags such as `IsProvisioned`, `NeedsCleanup`, `HasOrphanCandidate`, `IsBootstrapPending`, `IsBootstrapExpired`, `IsWorkerRegistered`, `WorkerStatus`, and retryable action names.
- DTOs do not include raw worker credentials, credential hashes, provider tokens, Steam credentials, or secret-bearing failure details.
</acceptance_criteria>
</task>
