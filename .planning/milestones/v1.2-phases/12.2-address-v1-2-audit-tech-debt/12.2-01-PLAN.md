<objective>
Regenerate the WebApp Kiota client from the current API OpenAPI document and remove the audit-relevant raw HTTP cloud
repository paths for admin cloud operations and server-owner cloud status.
</objective>

<threat_model>
- Threat: generated or hand-written WebApp models expose provider tokens, worker credentials, credential hashes, or
  bootstrap credential values. Mitigation: replace raw models only with API DTOs already verified as safe, then grep the
  generated and repository code for token/credential/hash fields before accepting.
- Threat: regeneration silently drops existing generated routes and regresses unrelated pages. Mitigation: run full
  WebApp build and inspect `ApiClient` top-level builders before repository rewiring.
- Threat: generated mutating routes make provision/teardown easier to invoke accidentally. Mitigation: keep UI action
  gating driven by persisted `CanProvision`/`CanTeardown`/retry flags and do not add background or automatic mutation.
</threat_model>
