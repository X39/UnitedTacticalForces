## Decisions & Deviations
The plan assumed Kiota regeneration might be blocked by local PostgreSQL/Docker. Docker was available in this session, so the live OpenAPI capture and regeneration path completed.

The regenerated client produced composed enum wrappers and several `*2` model names. Rather than rewriting the Blazor UI and repository contracts, the implementation keeps existing view models and adds a small compatibility alias file outside generated code.

`ResourceClaimRepository` was adjusted from generated `GetAsync` calls to `PostAsync` calls because the regenerated request builders now expose the API's mutating verb correctly. This was build fallout from the same Kiota regeneration.
