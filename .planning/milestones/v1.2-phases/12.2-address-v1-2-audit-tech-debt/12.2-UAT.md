## Live Hetzner UAT

Live provider mutation was not run.

Reason:

- No explicit operator approval was provided in this session for a specific Hetzner project, token reference, budget, shape, and cleanup window.
- No approved live Hetzner token reference/project was provided.
- Creating real Hetzner resources would be billable and is forbidden without the approval record described in `docs/operations/hetzner-live-uat.md`.

Current production safety gate:

- Provisioning and teardown require an enabled, verified `HetznerProviderConfiguration` with a non-empty token reference.
- The token reference must resolve server-side through `IHetznerSecretResolver`.
- If provider configuration is absent, disabled, unverified, or the token reference does not resolve, provisioning fails before provider mutation.
- Deletion, not power-off, remains the cost-stop boundary in teardown verification and the live UAT runbook.
