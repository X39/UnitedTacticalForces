<objective>
Show a rotated credential's new value once to the member who applied the rotation (UAT gap G-65-6 item 2), in the React app.

Purpose: UAT test 6 failed partly because a rotated value stayed invisible unless the member held the reveal claim, which most server managers lack. 65-16 made the rotate endpoint return the generated value once. This plan carries that value from the apply flow into the credentials row, where the member can copy it and hide it, without it ever reaching storage, caches, the URL, the console or an announcement.

Output: `hostingService.rotateSecret` returning the value, a one-time value store beside the draft in the Settings provider, a value-free apply result, the row showing the value with Copy value and Hide value, EN/DE copy and unit tests for display, copy, hide, staleness and leak hygiene.
</objective>
