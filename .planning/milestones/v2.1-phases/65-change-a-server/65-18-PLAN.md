<objective>
Let members type a deliberate value for every credential the game accepts one for, generated credentials included (UAT gap G-65-6 item 1), in the React app.

Purpose: UAT test 6 failed partly because members could not choose any value: `ServerSecretsPanel.tsx` shows the input only for non-generated secrets. 65-16 made the API accept chosen values for credentials the game declares and project `acceptsChosenValue` and `valueFormat`. This plan renders the input for those credentials, mirrors the API value rules before review so a member never applies a value the game cannot use, and lets the member check what they typed.

Output: schema-derived secret status types, pure value rules with tests, the input for accepted credentials with mapped errors and a Show typed value toggle, credentials in the Settings review gate, and EN/DE copy.
</objective>
