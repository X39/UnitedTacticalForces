<objective>
Complete the server side of the pending-start signal and harden the credentials API the UI now depends on. The tracer runs through the secret service and its controller: a credential set or rotate marks Credentials as pending, and an archived server rejects both with 409. Then the executor consumes Configuration and Credentials exactly where a Start or Restart command freezes them.

Purpose: configuration and secrets are re-resolved for every persisted worker command (`EnsureCommandPersistedAsync` calls `configurationService.ResolveAsync` and `secretService.CreateProtectedSnapshotAsync`), so the honest consumption point is the primary command of a Start or Restart job, not the enqueue (a restart that fails before command creation must keep the banner). The archived rejection aligns the API with the read-only Settings section (UI-SPEC) and closes the only change path that ignored archived state (RESEARCH A7).

Output: credential marks, archived rejection with 409 mapping and annotations, command-creation consumption, tests.
</objective>
