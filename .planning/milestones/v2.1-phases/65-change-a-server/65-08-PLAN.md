<objective>
Reflect the Files section's current folder in the URL (CHG-06, D-11). URLs are not a stable contract (D-00b), and the route manifest needs no change because it lists no query parameters. The tracer moves the folder and context from component state into `?path=` and `?area=` through a strict pure parser and makes folder links push history, so reload, sharing and Back work. Then invalid and missing paths fall back safely, focus and announcements follow folder changes, the Files guard moves onto the new leave guard (folder changes no longer count as leaving), and the immediate-change note appears.

Purpose: the panel keeps `path` in `useState` today, so a reload or a shared link always lands at the top level. Moving it to the URL also forces the old blanket navigation guard off, because every folder change is now a navigation (RESEARCH Pitfall 7).

Output: `filesLocation.ts`, URL-backed `ServerFilesPanel`, link styling, tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL to Files panel | `?path=` and `?area=` are attacker-controllable via shared links |
| Files panel to API | Folder paths are sent as the `path` query of the files endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-65-21 | Tampering | parseFilesPath | medium | mitigate | Strict parser rejects traversal segments, empty segments, backslashes, control characters and over-long values before any request; the API's `SafeServerPath.Normalize` remains the authoritative check |
| T-65-22 | Denial of service | not-found fallback | low | mitigate | Fallback only for non-root paths, at most one replace per location key; a root not-found shows the error panel without navigation (no loop) |
| T-65-23 | Spoofing | folder links | low | mitigate | Links are same-origin router locations built by `filesLocationTo` from the normalized path; no external URL or raw parameter is ever rendered as an href |
</threat_model>
