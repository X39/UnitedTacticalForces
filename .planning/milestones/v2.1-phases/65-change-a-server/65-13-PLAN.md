<objective>
Deliver the capability-driven mod pack chooser of CHG-01 in Settings (tracer-first): a member picks another Arma 3 pack in the new Mods panel, it is staged, reviewed and applied through the existing endpoint, and the Machine section stops offering the immediate pack change. Purpose: the mod pack change lives in the Machine section today as an immediate save without reasons or contents; D-01 moves it into the staged draft and D-05 asks for availability reasons and a contents diff, which the API provides since plans 65-05 and 65-09.

Output: `ModPackPanel`, `ModPackDiff`, `modPackDiff.ts`, `mods.css`, the Settings wiring, the Machine removal, tests.
</objective>
