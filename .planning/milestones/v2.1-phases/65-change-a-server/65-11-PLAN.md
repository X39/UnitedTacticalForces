<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API reveal response to browser | Plaintext secret values enter browser memory |
| Typed secret input to draft | New values live in the in-memory draft until applied |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-65-29 | Information disclosure | reveal flow | high | mitigate | `gcTime: 0` plus immediate `reset()`; value only in component state; 30 s timer, visibility, unmount, version and staging hide triggers; tests inspect the mutation cache, storage and console |
| T-65-30 | Information disclosure | typed secret after apply or discard | high | mitigate | Input value comes from the draft only; applied or discarded items leave the draft; test asserts the typed value is absent from the DOM after apply |
| T-65-31 | Elevation of privilege | Reveal control | medium | mitigate | Rendered only for `canRevealSecrets && revealable && isConfigured`; the API re-checks `RevealSecrets` and audits every reveal |
| T-65-32 | Information disclosure | error and announcement text | medium | mitigate | Fixed copy keys only; the reveal error never includes API text; announcements name the secret, never its value |
</threat_model>
