<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string to UI | `?action=` is attacker-controllable (shared link, crafted link) |
| deep link to lifecycle action | a link must never run an action by itself |
| forbidden or missing server to action hints | action names must not leak to a viewer who lacks permission |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-61-29 | Tampering | prototype-key lookup and markup injection through `?action=` | high | mitigate | actions found with Array.find, vocabulary via Map; the id is only ever a React text child truncated to 40 code points; tests for constructor, __proto__ and markup input |
| T-61-30 | Information Disclosure | action hints for a forbidden or missing server | medium | mitigate | the effect and notice live in the success branch after the forbidden, loading, error and not-found branches; test asserts no notice and no dialog for those cases |
| T-61-31 | Elevation of Privilege | a crafted link starting or stopping a server without consent (CSRF-style) | high | mitigate | the deep link only calls request(); the dialog opens with the dismiss button focused and only a user confirmation executes; test asserts executeAction is not called by the link |
| T-61-SC | Tampering | npm/pip/cargo installs | high | accept | no package installs in this plan |
</threat_model>
