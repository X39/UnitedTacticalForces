<objective>
Add the smallest backend projection the Mine filter needs (D-08): a nullable `CostOwnerUserId` on `GameServerDto`, set only when the cost owner is a user and the viewer may see the owner, then refresh the React OpenAPI snapshot and generated types.

Purpose: `GameServerDto.CostOwnerId` is the primary key of a `CostOwner` row, not a user id, so the React app cannot tell whether the signed-in user pays for a server. Without this field the Mine filter could only match the server creator and a member who pays for a server they did not create would never see it under Mine. The field is withheld whenever the viewer cannot see the owner, so it discloses nothing the viewer is not already allowed to know.

Output: one DTO member, one projection line, five focused xunit tests, a regenerated `utf-api.json` and `api.ts`.
</objective>
