<objective>
Complete the signal source (D-14): extend the tracer interceptor to cover every entity change that alters the fleet, add transaction-aware deferral so a signal never precedes the commit it announces, and add the one explicit signal for the bulk possible-cost update that bypasses `SaveChanges`.

Purpose: the tracer proved the transport with one trigger. The fleet shows server state, cost and pending work, so the signal must fire for deployment status and possible-cost changes, job transitions and server record changes, and it must be correct inside the explicit transactions the lifecycle executor and queue use. A signal published before commit makes the browser refetch the old state and then wait for a signal that already happened.

Output: the finished interceptor, an optional notifier dependency on the executor with one post-commit call, and two xunit suites.
</objective>
