## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stream frames to cache invalidation | untrusted frames can only cause a bounded, exact-key refetch |
| client reconnect loop to the API | a loop that never gives up must not become an accidental request flood |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-62-15 | Denial of Service | refetch amplification from a frame burst or from a broad key | medium | mitigate | leading-edge coalescer with at most one trailing run per 500 ms, exact-key invalidation only (never the per-server prefix), no frame content used; tests 1 and 2 |
| T-62-16 | Denial of Service | reconnect loop hammering the API during an outage | medium | mitigate | exponential backoff capped at 30 seconds with jitter, one pending timer at most, immediate attempts only on explicit viewer or browser signals (online, visible, reconnectNow); status tests prove the schedule |
| T-62-17 | Information Disclosure | socket opened for a viewer without server access | medium | mitigate | the provider enables the stream only when auth finished loading and canAccessGameServers is true, and the API gate independently forbids others; test 5 |
| T-62-SC | Tampering | npm/pip/cargo installs | high | accept | no package installs in this plan |
</threat_model>
