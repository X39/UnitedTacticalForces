<objective>
Let the control plane queue a normal Start or Stop job without a user (tracer-first): extract the body of `EnqueueActionAsync` into one shared core that takes an optional actor, a trigger and the evaluation instant, expose `EnqueueAutomatedActionAsync` for Start and Stop only, and add a read-only affordability pre-check for scheduled starts.

Purpose: research finding 1 - `EnqueueActionAsync` requires a `ClaimsPrincipal` with `Server.Operate` and `CanUseCostOwnerAsync`, so the evaluator cannot use it; reusing the Terminate fault path would lose data. AUT-05 requires the automatic stop to be the same durable job as a manual stop; D-AUTO-2 requires that it never becomes Terminate.

Output: the request record, the refactored lifecycle service, the affordability method, two test classes.
</objective>
