<objective>
Show the two new schedule outcomes of plan 68-21 on the rule's last-run line in English and German, so the user sees that a scheduled start is waiting for a shutdown, or why it was closed when the shutdown did not finish.

Purpose: UAT gap G-68-3 names the SkippedRunning copy as misleading for a stop in flight. After 68-21 the API reports WaitingForStop and SkippedStopUnfinished; without this plan the app shows only the plain "Last run: {time}." sentence for them.

Output: model and component mapping, EN/DE locale keys, rendering and model tests, the key list, and the UI-SPEC copy rows.
</objective>
