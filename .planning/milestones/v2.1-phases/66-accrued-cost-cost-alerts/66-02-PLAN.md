<objective>
Build the two external delivery channels the alert outbox will use, behind small outcome-typed adapters: a localized cost-alert message renderer with API-owned EN/DE resource text, a Discord direct message through the existing bot that never claims success while disconnected, and, after a blocking supply-chain checkpoint, an SMTP email sender on MailKit that is cleanly unavailable while unconfigured.

Purpose: CST-05 and CST-06 need the same alert by Discord DM and email (D-10, D-11), rendered in the recipient's language (D-12). The existing `WithDiscordAsync` silently does nothing when the client is not connected (RESEARCH Pitfall 3), so a delivery marked sent through it could be lost. The dispatcher in plan 66-07 consumes these adapters; this plan has no database or outbox code.

Output: `CostAlertMessageRenderer` and its keys, `MessageLocales`, `IDiscordDirectMessageSender`/`DiscordDirectMessageSender`, `DiscordBot.TrySendDirectMessageAsync`, `EmailOptions`, `IEmailSender`/`SmtpEmailSender`, `SmtpFailureClassifier`, the MailKit package reference, configuration defaults, and tests.
</objective>
