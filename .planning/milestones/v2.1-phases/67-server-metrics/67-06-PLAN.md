<objective>
Make the worker channel a single, bounded, push-capable connection per worker (tracer-first): a frame pushed through the registry reaches the connected worker and a newer connection replaces the older one, then the rate limit, the send timeout, credential rotation, restart redelivery and log hygiene.

Purpose: D-01 needs a way for the control plane to push Wake hints to a connected worker (plan 67-11 uses it); one connection per worker keeps deployment-scoped credentials meaningful; the caps and close paths keep a long-lived anonymous endpoint safe (RESEARCH Pattern 1, Pitfalls 3 and 12).

Output: the connection wrapper and the registry with their interfaces, the handler wired through them with a token bucket, the extended test host and tests.
</objective>
