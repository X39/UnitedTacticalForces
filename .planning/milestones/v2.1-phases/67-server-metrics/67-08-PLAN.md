<objective>
Build the worker side of the channel as a self-contained, tested client (tracer-first): connect with the bearer credential, send correlated requests and receive their acks, latch Wake pushes, then make the connection resilient to drops, credential rotation, oversized input and slow sends.

Purpose: D-01 and D-02 move every worker exchange onto one outbound socket. The client owns all transport concerns so the runtime (plan 67-14) only swaps HTTP calls for channel calls and keeps its journal and redelivery logic.

Output: the control channel interface, the connector abstraction with the ClientWebSocket implementation, the channel client and options, two exception types, the shared report mapper, and tests with a fake channel server.
</objective>
