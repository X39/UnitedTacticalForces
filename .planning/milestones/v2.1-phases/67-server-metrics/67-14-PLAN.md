<objective>
Switch the worker runtime to the channel (tracer-first): protocol 3 registration with every implemented game, heartbeat on its own timer, wake-driven claims and probes, and every report over the socket; then the metrics loop that sends machine and player readings from the primary host.

Purpose: D-01 and D-02 replace polling with the channel while keeping the durable journal and redelivery. Heartbeats independent of execution remove the fault cost-stop risk during long installs (Pitfall 5), and the registration fix restores ASKA (Pitfall 2). MET-02, MET-03 and MET-05 need the samples to travel only on the channel.

Output: the rewritten runtime loop, the metrics interval option, the Program wiring, and migrated plus new runtime tests with a fake control channel.
</objective>
