<objective>
Make command delivery and supersession push-driven (tracer-first): a committed worker command wakes the connected worker immediately, then the safety paths that cover a missed push and a cost-stop during a running command.

Purpose: D-01 forbids polling. The HTTP worker learned about new work by polling claims every 5 s and about a cost-stop by re-reporting Running every second (RESEARCH Pitfall 4). On the channel the API pushes Wake hints at the moments state changes and the worker asks the unchanged protocol service, so promptness improves while every decision stays in one place.

Output: the signal interface and queued implementation, the post-commit interceptor, `HasDeliverableCommandAsync`, the heartbeat wake, DI registration and tests.
</objective>
