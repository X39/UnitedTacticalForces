- Idempotency key: the fixed record identifier. The ledger already has a unique filtered index on `RecordIdentifier` (`IX_HostingCostLedgerEntries_RecordIdentifier_Unique`), so a second booking is impossible even under a race.

Prepaid windows would duplicate the real reconciler's work and would break the single-slice ledger shape that the costing scenario tests pin.
