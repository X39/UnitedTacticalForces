- `AskaConfigurationRenderer` renders `steam game port = 27015` and `steam query port = 27016`; `AskaWorkerCommandExecutor.ObserveRuntimeAsync` reads `_process.ObserveAsync` with `observation.IsRunning` and `observation.Identity?.Ready`. The executor takes optional constructor dependencies.
- `CounterStrike2RconClient` shows the loopback client and timeout style (connects to `IPAddress.Loopback`, linked token with a timeout).
- A2S_INFO request: `FF FF FF FF 54` + "Source Engine Query" + NUL, optionally followed by a 4-byte little-endian challenge; a reply starting `FF FF FF FF 41` carries a challenge to append and resend; a reply `FF FF FF FF 49` carries protocol (byte), name, map, folder, game (NUL strings), app id (int16), players (byte), max players (byte), bots (byte). A first header of `FF FF FF FE` is a split packet and is treated as malformed.
- `WorkerMetricUnavailableReasons` (plan 67-02, `X39.UnitedTacticalForces.Hosting.Contracts.WorkerProtocol`) defines measuring, query-failed, unsupported-platform and game-does-not-report, plus the `WorkerMachineReasons` and `WorkerPlayerReasons` sets.
