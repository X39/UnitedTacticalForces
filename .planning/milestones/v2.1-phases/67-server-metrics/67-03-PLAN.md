|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-67-01 | Spoofing | channel upgrade | high | mitigate | `AuthenticateAsync` before `AcceptWebSocketAsync`; per-frame re-verification inside every protocol service call; 401 before accept, 1008 after credential loss |
| T-67-02 | Information disclosure | command frames and logs | high | mitigate | Frames never logged; errors sanitized to 512 characters; generic Unavailable error; credential only in the bearer header, never in the query string |
| T-67-06 | Repudiation | lost supersession on the socket | medium | mitigate | Conflict maps to a Superseded ack exactly like HTTP 409; covered by the termination barrier test over the socket |
| T-67-SC | Tampering | npm/pip/cargo installs | high | accept | No package is installed by this plan; only framework WebSocket APIs are used |
</threat_model>
