Conversion recipe (every Wave 2 family plan follows it):
1. Headers (D-02, D-AUTO-3): one PageHeader (or PublicHero on Tier C hero pages) is the first heading; loading, forbidden, not-found and error early returns render the same PageHeader above LoadingState, ForbiddenState, EmptyState or ErrorState; no hand-written h1; the body below the header is a PageStack and no page root sets its own top or bottom margin.

3. Controls (D-07 to D-10): raw buttons and button look-alike class strings become ActionButton, ActionLink or ActionAnchor (one gold forward action per view, otherwise primary, ghost or danger; icon-only needs an aria-label); inputs become TextField, TextAreaField, SelectField, CheckboxField, RadioGroupField or SearchField; native disclosure blocks become Disclosure; hand-rolled dialogs become ConfirmDialog.
