## Task 2: Implement approval service and gate progression

- Add `ICloudSpendingPolicyApprovalService` and implementation for:
  - create-or-return pending request for an approval-required decision
  - approve pending request with expiration and reason
  - deny pending request with reason
  - validate an approved request against action, provider, billing account, billing assignment, game server, session, dry-run plan/resource, and expiration
  - acknowledge warn decisions by matching the persisted policy decision id and scope
- Update gate result DTOs to include approval request details when present.
- Update gate service so approved exceptions and acknowledged warnings allow execution while still rechecking policy/scope at execution time.

- Add admin-only endpoints to list, read, approve, and deny approval requests.
- Resolve approver/denier actors server-side and return `Unauthorized` when resolution fails.
- Map invalid state, stale approval, and validation exceptions to `BadRequest`.
- Verify API build and targeted approval tests when the test project allows.
