<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Billable action proposal to evaluation service | Untrusted action input crosses into policy classification and persisted decision history. |
| Evaluation service to provider boundary | The service must not cross into live cloud-provider mutation or provisioning/teardown execution. |
| Evaluation service to database | Decisions, input snapshots, risk fields, and errors become durable audit evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-06 | Tampering | `CloudSpendingPolicyEvaluationPayload` | mitigate | Validate idempotency key, enum, cost, currency, and owner identifiers server-side before decision persistence. |
| T-21-07 | Repudiation | `CloudSpendingPolicyDecision.IdempotencyKey` | mitigate | Add unique idempotency index and reload existing decisions unchanged on retry/race so duplicate records are not created and historical decision evidence is stable after restart. |
| T-21-08 | Elevation of Privilege | Direct endpoint bypass in later phases | mitigate | Expose a server-side `ICloudSpendingPolicyEvaluationService` that Phase 22 endpoints must call; this plan adds no client-side-only enforcement. |
| T-21-09 | Tampering | Provider mutation from evaluator | mitigate | Constructor reflection tests forbid provider, HTTP, provisioning, teardown, lifecycle queue, and generated client dependencies. |
| T-21-10 | Information Disclosure | Persisted input and failure fields | mitigate | Bound JSON/detail columns and defer full failure redaction coverage to Plan 03 before phase completion; no raw provider payload field is introduced. |
| T-21-11 | Tampering | Raw SQL/provider mutation | mitigate | Use EF LINQ and generated EF migration; no raw SQL mutation or provider API mutation is added. |
| T-21-SC | Tampering | Package-manager installs | accept | No new package install is required; research package audit lists none. |

No unresolved high-severity threat remains in this plan. Duplicate decision records and provider mutation are blocked by schema, service design, and tests.
