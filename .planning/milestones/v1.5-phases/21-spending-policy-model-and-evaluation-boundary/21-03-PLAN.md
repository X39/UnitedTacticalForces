<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Persisted v1.4 cost/reconciliation state to evaluator | Stored snapshots and reconciliation findings become decision inputs. |
| Exception/provider text to durable decision errors | Failure details can cross into persistent audit records if not sanitized. |
| Evaluator to later policy gates/actions | Later phases will rely on these decisions to block, warn, require approval, or compute automatic actions. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-12 | Tampering | Risk input aggregation | mitigate | Query persisted `CloudCostSnapshotContributions`, `CloudProviderReconciliationRuns`, and findings with EF LINQ; no raw SQL/provider mutation is used. |
| T-21-13 | Information Disclosure | `InputSnapshotJson`, `RiskDetailsJson`, `SanitizedFailureSummary`, `SanitizedFailureDetails` | mitigate | Serialize allowlisted fields only, cap JSON/detail strings, and sanitize failures with `LifecycleFailureReasonSanitizer`; tests assert secret words are absent from persisted output. |
| T-21-14 | Repudiation | Idempotent risk decisions | mitigate | Preserve Plan 02 idempotency behavior while adding risk counts and snapshots; tests cover retry and restart after risk classification and assert the original persisted evidence is not mutated. |
| T-21-15 | Elevation of Privilege | Direct endpoint bypass in later phases | mitigate | Final provider-mutation/source scans and service tests prove the server-side evaluator is the only Phase 21 decision boundary; Phase 22 must call it at all billable endpoints. |
| T-21-16 | Denial of Service | Unbounded persisted input/error text | mitigate | Bounded entity fields and truncation prevent unbounded JSON or exception text persistence. |
| T-21-17 | Tampering | Unknown billable provider resources | mitigate | Unknown provider resources escalate to `Deny` so policy decisions do not silently ignore cost risk. |
| T-21-SC | Tampering | Package-manager installs | accept | No new package install is required; research package audit lists none. |

No unresolved high-severity threat remains in this plan. Secret leakage, duplicate decisions, ignored risk inputs, and provider mutation are all covered by automated tests or source gates.
