## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin/API input to policy persistence | Policy thresholds and action settings cross from request payload/service input into durable policy state. |
| Policy persistence to later billable gates | Later phases will trust effective policy configuration when classifying or gating cost-generating actions. |
| EF model to PostgreSQL schema | Policy definitions and audit metadata become durable database records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-01 | Tampering | `CloudSpendingPolicyConfigurationPayload` and `CloudSpendingPolicyConfigurationService` | mitigate | Validate scope, non-negative amounts, threshold ordering, automatic action threshold, effective date range, stale reconciliation window, and enum allow lists server-side before `SaveChangesAsync`. |
| T-21-02 | Tampering | Policy thresholds in `CloudSpendingPolicies` | mitigate | Persist audit actor FKs and timestamps, use EF-tracked updates, and cover create/update validation with `CloudSpendingPolicyConfigurationTests`. |
| T-21-03 | Elevation of Privilege | Direct endpoint bypass in later phases | mitigate | This plan creates no billable endpoint gate; it provides the server-side configuration service that Phase 22 policy gates must call before billable actions proceed. |
| T-21-04 | Information Disclosure | Policy DTO/payload/entity fields | mitigate | Store only threshold/action/scope/audit metadata and reject secret-bearing fields; acceptance scans for token/password/secret/authorization/bearer strings. |
| T-21-05 | Tampering | EF migration and raw SQL/provider mutation | mitigate | Use EF LINQ and `dotnet ef migrations add`; no raw SQL, provider client, WebApp generated client, or provider mutation code is added. |
| T-21-SC | Tampering | Package-manager installs | accept | No new npm, pip, cargo, or NuGet package install is required; research package audit lists none. |

No unresolved high-severity threat remains in this plan. Policy threshold tampering is mitigated by validation tests before any later gate consumes policy rows.
