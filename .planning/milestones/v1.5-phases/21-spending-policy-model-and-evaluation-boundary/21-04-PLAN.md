## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Administrator request to policy API | Authenticated administrator input crosses into persisted policy configuration and dry-evaluation records. |
| Policy API to internal services | Controller delegates to server-side services that own validation, persistence, idempotency, and risk classification. |
| Dry evaluation API to later action phases | Phase 21 exposes classification only; action execution remains outside this API boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-18 | Elevation of Privilege | `CloudSpendingPoliciesController` | mitigate | Add class-level `[Authorize]` and method-level `[Authorize(Claims.Administrative.Server)]`; controller tests assert every admin method has the server claim policy. |
| T-21-19 | Spoofing | Actor resolution for writes/evaluations | mitigate | Resolve `User` through `GetDatabaseUserAsync` before calling services and return `Unauthorized` when no database user exists. |
| T-21-20 | Tampering | Policy definition payloads | mitigate | Delegate validation/persistence to `ICloudSpendingPolicyConfigurationService`; controller maps validation exceptions to `BadRequest` and does not bypass service validation. |
| T-21-21 | Information Disclosure | Policy/decision DTO responses | mitigate | Return DTO transforms only, add forbidden field-name tests, and do not expose provider tokens, credentials, raw provider payloads, or unredacted exception text. |
| T-21-22 | Elevation of Privilege | Dry evaluation endpoint accidentally executing actions | mitigate | Controller depends only on policy services and `ApiDbContext`; tests/source gates forbid provider clients, lifecycle job service, provisioning, teardown, generated clients, and provider mutation method names. |
| T-21-SC | Tampering | Package-manager installs | accept | No new package install is required; research package audit lists none. |

No unresolved high-severity threat remains in this plan. Authorization, actor resolution, DTO safety, and dry-evaluation isolation are covered by targeted controller tests.
