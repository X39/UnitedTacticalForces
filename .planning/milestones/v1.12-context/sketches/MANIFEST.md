# Sketch Manifest

## Design Direction

Small account surfaces should feel like part of the cinematic operations UI, not like a stock Fluent account card. The profile menu should use the UTF dark/gold system, expose useful identity and permission context, and act as a deliberate bridge between Community Shell and Command Center Shell.
