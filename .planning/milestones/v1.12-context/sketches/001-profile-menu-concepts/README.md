# Sketch 001: Profile Menu Concepts

## Design Question

Which account popup structure best fits the cinematic dual-shell UI while exposing useful personal context?

## How to View

Open `.planning/sketches/001-profile-menu-concepts/index.html`.

## Variants

- **A: Community Dossier** - A profile-forward community menu with public identity, verification, linked accounts, and a clear Command Center bridge.
- **B: Command Operator Card** - Selected direction. A compact operational account card for the Command Center top bar with role, authority, and attention context.
- **C: Mobile Identity Sheet** - A responsive account sheet designed for narrow screens with grouped identity, permissions, and session actions.

## What to Look For

Compare how much personal information feels useful before the popup becomes heavy, whether shell-switch actions are obvious, and whether the account menu feels native to both Community and Command Center surfaces.
