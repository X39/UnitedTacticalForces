Expose the admin billing import API and persist parsed Hetzner billing facts safely.

<tasks>

## Task 1: Add DTOs and payload

- Add DTOs for import batches and line items with safe metadata and sanitized diagnostics only.
- Add a creation payload that carries CSV content, source file metadata, source period, invoice/reference metadata, and duplicate handling intent.

## Task 2: Add import service

- Compute SHA-256 source hashes from incoming content.
- Detect duplicate imported batches by provider/source hash.
- Persist successful imports, failed imports with sanitized diagnostics, and explicit ignored/superseded duplicate attempts.
- Add hosting audit records for import attempts without storing raw CSV content.

## Task 3: Add controller and tests

- Add admin-only endpoints to create imports and inspect batches/items.
- Add service tests for successful import persistence, duplicate handling, parser failure status, restart-safe reload, and redaction.
- Add reflection/controller tests for authorization-sensitive API boundaries.
