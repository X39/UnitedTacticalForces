<objective>
Add the persistent matching model and exact provider-resource matching service foundation.
</objective>

<tasks>

## Task 1: Add match contracts and entities

- Add match run status, match method, and review status enums under `sources/Contract/GameServer`.
- Add `CloudBillingMatchRun` linked to one import batch with provider identifier, algorithm version, status, counts, requester, timestamps, and sanitized failure fields.
- Add `CloudBillingMatchRecord` linked to a run and import line item with optional inventory/session/game-server/billing/cost contribution links, match method, confidence, review status, amounts, currency, and sanitized explanations.

## Task 2: Register EF model

- Add `DbSet` properties to `ApiDbContext`.
- Configure delete restrictions, useful query indexes, and an idempotency index for import batch plus algorithm version.
- Add an EF Core migration for the new tables and indexes.

## Task 3: Implement exact matching foundation

- Add `ICloudBillingMatchingService` and implementation.
- Load imported line items for a completed import batch.
- Match exact provider resource references by provider identifier, resource kind, and provider resource id.
- Persist unmatched and ambiguous exact-match outcomes as unresolved records.
- Return existing completed match runs for the same batch/version without duplicating records.

## Task 4: Add exact-match tests

- Cover exact server/IP/volume matches, missing inventory, ambiguous duplicate inventory records, and idempotent reruns.
