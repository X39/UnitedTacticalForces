## Artifacts This Plan Produces

- `ICloudProviderReconciliationService` with `RunHetznerReconciliationAsync`, run lookup, and finding lookup methods.
- `CloudProviderReconciliationService` that persists running, completed, and failed runs in transactions.
- Reconciliation comparison logic for unknown provider resources, missing provider resources, state mismatches, and cleanup-needed billable resources.
- Secret-safe audit records for completed and failed runs.
- Admin-only API endpoints, preferably on the existing cloud inventory admin surface:
  - `POST /cloud-inventory/reconciliation/runs`
  - `GET /cloud-inventory/reconciliation/runs`
  - `GET /cloud-inventory/reconciliation/runs/{runId}`
  - `GET /cloud-inventory/reconciliation/runs/{runId}/findings`
- DTOs and transforms for run and finding records.
- Tests for run persistence, failure sanitization, attribution preservation, no provider mutation, restart-safe reads, and admin authorization metadata.
