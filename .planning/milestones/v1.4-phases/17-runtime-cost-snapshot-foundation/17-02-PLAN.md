<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Provider inventory to cost service | Persisted provider-resource lifetime records are trusted as durable facts; runtime state is not trusted for billing stop decisions. |
| Billing assignment history to cost summaries | Historical owner intervals cross into cost aggregation and must not be collapsed to the current owner. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-06 | Tampering | `CloudCostIntervalCalculator` | mitigate | Tests prove only `TimeStampDeleted` stops provider cost and runtime/power/cleanup states are ignored for COST-11. |
| T-17-07 | Repudiation | Historical owner aggregation | mitigate | Contribution rows and summaries keep `BillingAccountFk` and `BillingAssignmentFk` per interval so old cost is not reassigned to the current owner. |
| T-17-08 | Information Disclosure | Service constructor dependencies | mitigate | Reflection test blocks `IHetznerCloudClient`, `IHttpClientFactory`, and `HttpClient` so this phase cannot leak tokens through live provider calls. |
| T-17-09 | Elevation of Privilege | Public endpoints | accept | This plan adds no controller, DTO, generated client, or WebApp route; Phase 19 must add owner/admin authorization before user-facing cost history. |
| T-17-10 | Denial of Service | Interval calculation over persisted rows | mitigate | Load only resources and billing assignments for the requested session/game server, and skip non-overlapping intervals rather than expanding per-hour rows. |
| T-17-SC | Tampering | NuGet installs | accept | No package-manager install is required. |

No unresolved high-severity threat remains in this plan; the highest-risk provider-boundary and attribution threats are covered by automated tests.
