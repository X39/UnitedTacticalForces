<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated actor to preflight API | Actor submits approval and access evidence that could be inaccurate or secret-bearing. |
| Server-owner scope to server evidence | Non-admin operators can see/write only scoped server preflight state. |
| Preflight service to audit log | Operator evidence becomes durable audit text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-04 | Spoofing | Access evidence | mitigate | Store actor id, role/scope label, route, outcome, and timestamp; do not treat access evidence alone as provisioning authorization. |
| T-40-05 | Information Disclosure | Access evidence payload | mitigate | Allowlisted fields only; reject common secret/session markers; tests assert no cookie/bearer/header persistence. |
| T-40-06 | Elevation of Privilege | Preflight write routes | mitigate | Require server configuration authorization and validate selected server/owner/plan relationships server-side. |
| T-40-07 | Repudiation | Approval/access evidence | mitigate | Append hosting audit records with actor id and sanitized summary/details. |
| T-40-SC | Tampering | Package supply chain | accept | No package-manager install is planned. |
</threat_model>
