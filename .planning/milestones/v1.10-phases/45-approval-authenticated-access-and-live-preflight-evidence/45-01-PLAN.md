| Boundary | Description |

| Operator browser to WebApp state | Operator types approval evidence into the browser. |
| WebApp to API repository facade | Approval command crosses from UI state to durable API persistence. |

| T-45-02 | Tampering | Approval command builder | mitigate | Build owner/server/plan ids from current selected state and rely on API validation for final relationship checks. |
| T-45-03 | Repudiation | Approval submission | mitigate | Existing API service persists actor/approver/timestamps and appends hosting audit rows. |
| T-45-04 | Elevation of Privilege | UI action availability | mitigate | UI only enables when selected state is coherent; API authorization remains authoritative. |
| T-45-SC | Tampering | Package supply chain | accept | No package or registry changes are planned. |
